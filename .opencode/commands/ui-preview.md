# UI Preview

1. Inspect the existing page/component.
2. Capture baseline screenshot if appropriate.
3. Implement only the requested UI change.
4. Start local preview.
5. Capture desktop and mobile screenshots.
6. Run visual checks.
7. Run relevant tests.
8. Save artifacts under `artifacts/ui/`.
9. Report screenshot paths and preview URL.

Do not deploy production. If the user asked to preview first, stop after reporting local visual results.
